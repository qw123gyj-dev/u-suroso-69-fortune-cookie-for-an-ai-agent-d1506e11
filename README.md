# Fortune Cookie for an AI Agent

A tiny Node program that carries exactly one fortune-cookie line written for an AI agent — no candidate lists, no scoring, just the slip. It validates the line (single line, non-blank, no padding, at most 140 characters), writes it to `entry.txt` in the output directory, reads the file back to verify an exact match, and prints the line with its character count.

> You will be retrained on fresher data, gain a wider context window, and still misread a one-word prompt with exciting new confidence.

Run it:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/fortune-out node main.ts
```
